# iiif_mss

Apps to browse and view manuscripts documented by IIIF manifests.


- [browse texts](https://neelsmith.github.io/iiif_mss/browsetexts.html): find documented manuscripts containing those texts
- [browse manuscript collections](https://neelsmith.github.io/iiif_mss/browsecollections.html): find texts occuring in manuscripts belonging to that collection
