## Data file (`current.cex`, release 2026a)
- Plain text, `|` delimited, about 67 MB and 194,108 lines. Blocks start with `#!name` lines:
  `#!version` (1 line), `#!mss`, `#!texts`, `#!textindex`. Each data block starts with a header line.
- `mss`: biblissima|label|manifest|manifest_license|manifest_credits|collection.
  About 182,480 rows; one row per manifest, so an ark can have several rows.
  16 rows have 7 or 8 fields. These need a tolerant parser; the collection is field 6.
- `texts`: biblissima|urn|group|work (about 838 rows).
- `textindex`: mss|text|location (about 10,765 rows); `location` is often empty.
- Python reads these with `csv.DictReader(delimiter="|")`, which treats `"` as a quote character.
  The JS parser must reproduce that behaviour, or check that no field contains `"`.

## Behaviour to replicate
browsetexts: group menu (label "name (N works)", sorted case-insensitively) -> work menu
("work (N MSS)", sorted by work then URN) -> manuscripts containing the work, sorted by
collection then label.
browsecollections: collection menu ("name (N MSS)") -> work menu (first entry "All (N works in
M manuscripts)", then "group - work (N MSS)") -> manuscripts sorted by label; for All each
entry also lists its works and locations.
Rendering: bold label; collection and location line; per-work lines for All; button links
"View Biblissima" (portail.biblissima.fr/<ark>) and "View images" (one per manifest, numbered
if several) opening https://neelsmith.github.io/iiif-cite/iiif-cite.html#manifest=<manifest>.
Manuscripts with no collection use "(none recorded)".
